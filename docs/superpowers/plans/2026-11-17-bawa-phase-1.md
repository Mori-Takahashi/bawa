# BAWA Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the core path of BAMA into BAWA: a WinUI 3 app template that builds, tests, and snapshots itself on Windows, plus the skills that use it, then prove it by building milestone 1 of a disk space app.

**Architecture:** The template is a .NET 10 solution with three projects (WinUI app, `.Kit` logic library, xUnit tests), PowerShell 5.1 scripts in `tools/`, and C# file programs run with `dotnet run tools/<name>.cs`. Skills are Markdown, rewritten in place under new names where the name was Mac-specific. Mac skills not yet ported stay in the tree, unlisted.

**Tech Stack:** .NET 10, Windows App SDK (current stable), WinUI 3, CommunityToolkit.Mvvm, Microsoft.Data.Sqlite, xUnit, Svg.Skia, Windows PowerShell 5.1.

**Spec:** `docs/superpowers/specs/2026-11-17-bawa-windows-port-design.md`

## Global Constraints

- Target framework `net10.0-windows10.0.19041.0` for the app, `net10.0` for `.Kit` and tests. `WindowsPackageType=None`, `WindowsAppSDKSelfContained=true`, `RuntimeIdentifier=win-x64`.
- Every script runs under Windows PowerShell 5.1 (no `pwsh`, no `&&`, no `??`, no ternary). Skills always call them as `powershell -NoProfile -ExecutionPolicy Bypass -File tools\<name>.ps1`, because the default execution policy blocks `.ps1` files.
- C# tools run as `dotnet run tools\<name>.cs -- <args>` with `#:package` directives. No extra project files for tools.
- Test store: `APP_STORE` must resolve (after `Path.GetFullPath` and long-path expansion) to a path under `Path.GetTempPath()`. Otherwise snapshot, seed, and self-test print `<MODE> refused: set APP_STORE to a file in %TEMP%` and exit 1.
- Real database: `%LOCALAPPDATA%\<AppName>\<AppName>.db`. Build output: `%LOCALAPPDATA%\<AppName>\build`. Install: `%LOCALAPPDATA%\Programs\<AppName>\`. Snapshots: `%TEMP%\<AppName>-shots\`.
- Folder paths come from `Environment.GetFolderPath` / `$env:LOCALAPPDATA` / `[Environment]::GetFolderPath('Programs')`, never hard-coded (German Windows names folders differently).
- Numbers written to files use `CultureInfo.InvariantCulture`.
- Spacing on a 4 px grid (effective pixels): raw numbers are 0, 1, 2, or multiples of 4. Tokens: `Xs 4, Sm 8, Md 12, Lg 16, Xl 20, Xxl 24, Section 32, Margin 24`. The page margin is 24 (Mac template: 20), closer to Fluent page padding.
- Skills: English, description is a context pointer ("<what>. Use when ..."), every step ends on a checkable condition, every skill ends with a `Done when` line, no em dashes, one skill calls another with "Call the Skill tool with `<name>`".
- Placeholders in the template: `__APP_NAME__` only. No bundle id on Windows. `new-app.ps1` takes `<AppName> [parent-folder]`.
- Author `Lyonel Berzen`, URL `https://github.com/Mori-Takahashi`, repo `https://github.com/Mori-Takahashi/bawa`. Credit line: "Based on BAMA by Dave Ebbelaar." LICENSE keeps "Copyright (c) 2026 Dave Ebbelaar" and adds "Copyright (c) 2026 Lyonel Berzen".
- Plugin `version` `0.1.0` at the end of this plan.

## Review Focus

1. **Paths with spaces** (`C:\Users\Max Muster\Documents\My Apps`): `new-app.ps1`, `build.ps1`, `snap.ps1`, and `selftest.ps1` work there. Test: Task 9 runs the end-to-end check in a temp folder whose name contains a space.
2. **App already running during a build**: the exe is locked. `build.ps1` without `-Open` stops with `close <AppName> first, or run build.ps1 -Open`; with `-Open` it stops the running copy first. Test: Task 9 step.
3. **`APP_STORE` given as a short 8.3 path or a relative path** (`C:\Users\LYONE~1\AppData\Local\Temp\x.db`, `..\x.db`): the guard compares normalized long paths. Test: Task 3 `StorePathTests`.
4. **Windows 10 or Mica unavailable**: the window falls back to the default background with no crash, and snapshots still write PNGs. Test: Task 4 checks `MicaController.IsSupported()` before setting the backdrop; self-test check "window has a backdrop or a solid fallback".
5. **German locale**: layout JSON uses `.` as decimal separator and `check-layout.cs` parses it correctly on a `de-DE` machine. Test: Task 6 `Parses_layout_json_under_german_culture`.
